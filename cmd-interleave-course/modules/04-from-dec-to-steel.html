变量如何变成钢板结果

算法嘴里说的是 0 到 1 之间的归一化数字, 工程软件嘴里说的是腹板高度、板厚和应力。中间这层翻译, 就是这条链路最“像工程”的地方。

第一步: 把归一化变量映射成真实尺寸

CODE 
Range = Prob.Ub{t} - Prob.Lb{t};
Lower = Prob.Lb{t};
x = Decs(:, 1:D) .* Range + Lower;

[Objs, Cons] = Prob.evaluate(x, t);
Algo.FE = Algo.FE + size(x, 1);
PLAIN ENGLISH

先算这个任务每个变量允许活动的真实跨度。

再取出下界, 也就是每个变量最小能到哪。

把 0 到 1 的归一化决策变量拉伸成真实工程尺寸 `x`。

把真实尺寸交给问题对象评估。此时算法已经不用直接碰上下界了。

本次真正做了多少次评估, FE 就加多少。

第二步: 真实尺寸被送进 APDL 和 ANSYS

1
`Ship_Panel_Problem.generate_mac()`

把 `h_web_L1`、`b_bot_R` 这类尺寸拼成 APDL 宏脚本。你可以把它理解成“给 ANSYS 写施工说明书”。

2
`run_ansys_eval()`

创建工作目录、写 `.mac`、找到 `MAPDL.exe`、启动批处理求解, 然后读取结果文本。

3
约束和目标回到优化器

目标值用 FEA 质量, 约束则来自最大弯曲应力、最大剪切应力和几何顺序约束。

第三步: ANSYS 回来的东西会被整理成优化能懂的格式

CODE 
con(1) = max_bend - task.bend_allow;
con(2) = max_shear - task.shear_allow;

h_web_L1 = x(1);
h_web_L2 = x(5);
con(3) = h_web_L2 - h_web_L1;
PLAIN ENGLISH

第一条约束问的是: 最大弯曲应力有没有超过任务允许值。

第二条约束问的是: 最大剪切应力有没有超标。

接下来开始看几何关系, 先取中心纵骨高度。

再取侧纵骨高度。

如果 `h_web_L2 - h_web_L1` 是正的, 说明侧纵骨反而比中心纵骨还高, 这条几何约束就被破坏了。

!
当 ANSYS 出错时, 优化不会立刻崩

代码会给这个候选解一个巨大的惩罚值, 让算法自然把它淘汰掉。这是很常见的“让搜索继续往前走”的工程手法。
