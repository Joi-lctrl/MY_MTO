i
MATLAB basics: rng / containers.Map / anonymous function

rng(seeds(rep)) 不是“随机一下”, 而是把随机流重置到一个固定起点, 所以这次 rep 里所有后续采样都能复现。

containers.Map 像一个可共享的字典, 适合把“跨函数要继续更新”的状态放进去。

@() live_update_with_earlystop(...) 是匿名函数句柄, 这里的作用是延迟执行: 先把上下文捕获好, 等 notTerminated 的时机再真正跑。

MATLAB basics: size(x,1), numel(x), zeros(...)

size(x,1) 是同一类 size(...) 写法里的“数行数”形式。这里代码实际用的是 size(tmp, 2) 来数列数, 因为它在追踪重采样结果的列宽。

zeros(...) 是全零预分配的同类写法。这里附近用的是 nan(Reps, nPoints), 因为 NaN 更适合标出“还没写入”的空位, 不会把缺失数据伪装成真实的 0。
