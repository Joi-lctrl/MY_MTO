Runtime Bookkeeping

这一页把 Algorithm.notTerminated 讲成一个执行检查点: 它不只是返回 true / false, 它还会在每代末尾把结果、人口大小、FE 和回调都补齐。

i
这一步的本质是“写 checkpoint”, 不是“再跑一次算法”

notTerminated 只在代末做收尾: 它把当前代的最佳解或整个人口存进 Algo.Result, 再把人口大小写进 PopSize_Gen。真正的搜索算子并不在这里执行。

L152 调用外层脚本挂进来的状态回调; 到这里, 一个代末检查点才算彻底结束。

i
为什么这里像“检查点”而不是“终点”

因为它会先记账、再推进、再回调。只要 flag 还没被外部条件打成 false，算法就会回到主循环继续下一代。这个函数是节拍器, 不是终止按钮。
